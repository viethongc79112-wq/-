吴言网站 · GitHub Desktop → Cloudflare Pages

1. GitHub Desktop 选择桌面“吴言个人简历网站”对应的仓库。
2. 勾选本次修改，填写摘要，Commit to main，再点击 Push origin。
3. 到 GitHub 检查仓库根目录有 package.json、src、public、scripts，而不只是压缩包。
4. 在 Cloudflare Pages 确认连接的是这个 GitHub 仓库，生产分支 main。
5. 构建命令：pnpm run build
   构建输出目录：dist
   根目录：留空
   框架：Vite（或 None）
   Node.js：24（项目的 .node-version 已指定）
   pnpm：11.19.0（package.json 已指定；后台环境变量可设 PNPM_VERSION=11.19.0）
6. 等待部署成功，再打开项目的 pages.dev 地址检查。

全部 10 部作品使用 B站，需要联网。部署包自动排除本地视频，无需上传压缩包或原视频。
若 Cloudflare 项目仍绑定之前删除或重建过的仓库，需要先确认 GitHub 连接有效。
