# 吴言个人网站设计依据

已由对话确认；用户要求直接以 React + Vite 实现，PC 优先，版心最大 1700px。

1. 网站类型：单页纵向个人介绍与作品集。首页、视频作品、AIGC、关于我、联系我依次出现；不跳转作品详情页面。
2. 目标用户：了解吴言专业背景、审美及制作能力的同行、合作伙伴及招聘方。
3. 核心模块：首页姓名和职业身份配多帧作品；视频作品与 AIGC 同等地位；个人介绍含证件照、工作照、教育、实践、荣誉；联系只含手机、微信号和二维码。
4. 视觉风格：深石墨 #101214，灰白 #eceeea，次要文字 #989e9f，银灰细节。开放版式、细线、直角影像、少量冷灰蓝；无大面积霓虹、卡片套卡片、虚构数据。中文主导。
5. 交互：原生纵向滚动，锚点导航；首页六帧以 AIGC 为主；点击作品使用原生 dialog 在同页播放，支持键盘 Escape、关闭按钮、原生媒体控制、焦点恢复；关闭保留滚动位置；尊重减少动态偏好。
6. 参考素材：用户作品集目录。视频作品：云南风光、长广文艺片、转身即是出征、香格里拉（拍摄与剪辑）；易果应聘考核试剪（剪辑）。AIGC：踢开门、六尺巷、HOPE、向未来生长、侠客。首页排除侠客，包含其余四部 AIGC 以及云南风光、香格里拉。仅对简历明确匹配的项目使用年份、荣誉和职责；长广文艺片不自动等同于简历纪录片。
7. 输出要求：可本地运行和构建的 React + Vite 页面，1700px 最大版心，手机基本适配，真实可播放的视频和封面，配置集中管理，运行说明。

## 页面构图
- 导航：姓名字标在左，中文锚点在右，下方细线。
- 首页：大幅姓名与职业身份，上下错落的六帧电影带，中间 HOPE 主画面突出。只使用身份、作品名、分类及向下浏览提示，不额外创造宣传口号。
- 两个作品板块：各有章节号、标题、简短能力描述；两张大幅精选作品配三张次级作品，竖屏踢开门完整保留比例。
- 关于我：左侧工作照，右侧短介绍及较小肖像，下方教育/经历/荣誉清晰分行。
- 联系：轻量收尾，电话可复制及拨号，微信资料未提供时不生成虚假内容或二维码。
